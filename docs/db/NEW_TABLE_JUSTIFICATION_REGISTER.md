# New Table Justification Register

Purpose: enforce kernel-first table discipline for V2 schema evolution.

Rules:
- Do not create a new table unless existing governed structures are insufficient.
- Allowed reasons: kernel integrity, engine integrity, tenant isolation, security hardening, migration authority.
- Weakly justified proposals must be marked `deferred` and not created.
